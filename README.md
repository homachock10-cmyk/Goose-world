# Мир гусей 🪿

Небольшая мобильная 2D-игра, вдохновлённая комедийными играми про озорного гуся. Это самостоятельная игра для Android: ходи по деревне, гогочи, собирай яблоки, кради предметы и выполняй забавные задания.

## Сборка APK

Каждый push в `main` запускает GitHub Actions. Открой вкладку **Actions**, выбери успешный запуск **Build Android APK**, затем скачай артефакт **Mir-Gusey-APK**. Внутри будет `app-debug.apk`.

## Управление

- Кнопки со стрелками или WASD — движение.
- **ГАК!** — гоготать и пугать жителей.
- **Взять / бросить** — подобрать предмет или отпустить его.
- **Задания** — посмотреть цели.

Игра работает офлайн и не требует разрешений на телефоне.
